Claude Wake Word Detector

A professional Windows desktop application that listens for the "Hey Claude" wake word and executes customizable commands.

FEATURES:
- Voice wake word detection
- System tray integration
- Settings panel
- Professional UI
- Start/Stop control
- Test mode

USAGE:
1. Launch the application from desktop or start menu
2. Configure your Picovoice API key in Settings
3. Click "Start Listening"
4. Say "Hey Claude" to trigger commands
